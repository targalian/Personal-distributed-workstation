# iter-37：项目描述编辑历史（UI-036）

原有撤销／重做仅在 DAG 视图可见，每个输入事件生成一个快照，保存会清空历史。本轮将入口移至工作区顶部，文档、DAG 和 Markdown 预览共用历史。

## 完成内容

- 每个会话独立保留最近 50 步；连续同字段输入在 1 秒间隔内合并，失焦或其他编辑操作结束分组。
- 文档标题、章节、节点属性、拖动、删除子树和依赖操作均可恢复；无变化操作不占用历史或破坏重做。
- 保存保留历史；撤销仅修改本地内容，不回退服务端 revision，需再次保存才会更新服务端。
- 对比最后保存的内容决定同步状态，忽略 API 序列化造成的对象字段顺序变化。
- Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 或 Ctrl+Y 重做；范围限定在工作区，不接管聊天输入。节点属性未提交时使用浏览器原生文本撤销。
- 保留字段焦点、展开章节和存在的 DAG 节点焦点；切换相同版本会话保留历史，显式重载或外部新版本建立新历史边界；冲突保留本地草稿和历史。
