单仓库包含 Python 后端 `lan_mesh/` 与 Tauri 桌面端 `quicklan-main/`。

- 进程角色：`main.py` 通过 `argparse` 分发到三种角色——`station`（StationController，基础设施管理 + Web UI）、`secretary`（SecretaryController，中心控制节点，含 ProjectManager/Orchestrator/MCPGateway）、`worker`（WorkerAgent，各主机守护进程）。`station` 支持同进程动态激活/停用 Secretary 组件（`activate_secretary()` / `deactivate_secretary()`），实现「纯基础设施模式」与「项目管理模式」切换。
- 通信协议：UDP 广播端口 45454 做设备发现（`protocol.DiscoveryPacket` + `discovery.DiscoveryService`），HTTP REST 用于 Worker→Secretary 注册/心跳/文件下载，WebSocket 用于实时推送。
- 配置体系：`config.py` 使用 Pydantic BaseModel 强类型校验，`load_config()` 按显式参数 → `LAN_MESH_CONFIG` 环境变量 → `~/.lan_mesh/config.yaml` → 项目根 `config.yaml` 顺序加载；`load_model_pool()` 同理加载 `model_pool.yaml`。
- 数据与共享：SQLite 持久化（`database.Database`），`shared_folder.SharedFolderManager` 在各节点维护同一目录作为协作空间；`host_info` 采集 CPU/内存/磁盘/OS/网络信息并通过 UDP/HTTP 上报。
- 高级能力：`agent_runtime` + `pm_agent` 在 Worker 侧运行 PM Agent 子进程；`mcp_gateway` 暴露 MCP 工具；`skill_registry` 扫描 `skills/` 目录注册技能；`bot_gateway` 集成企业微信/Telegram 消息通道。
- 前端：`quicklan-main/` 为 Tauri 应用，Rust 后端 (`src-tauri/src/`) 复用 LAN 发现与协议，通过 Tauri commands 调用本地 API，React+Vite 渲染仪表盘。
