- **核心架构**：采用中心化的 Secretary（控制节点）与分布式的 Worker（工作节点）主从模型，通过 `main.py` 统一入口根据角色启动不同控制器。
- **通信层**：集成 `DiscoveryService` 实现基于 UDP 广播的设备自动发现与心跳保活，结合 FastAPI 提供的 RESTful API 与 WebSocket 实现实时状态同步与指令下发。
- **数据持久化**：使用线程安全的 SQLite 封装类 `Database` 存储主机注册信息、Agent 能力卡片、任务生命周期及项目预算记录。
- **业务逻辑分层**：
  - **接入层**：`api.py` 定义 Secretary 与 Worker 的路由边界，处理注册、心跳及文件传输请求。
  - **协调层**：`Orchestrator` 负责任务分解与调度，`StationDirector` 执行主机评级与出入站管理，`ModelRouter` 实现基于加权评分的智能模型路由。
  - **基础设施层**：`SharedFolderManager` 管理跨主机文件共享，`MCPGateway` 聚合外部工具能力。
