- 采用字典路由映射技能类型：在 `AgentRuntime` 中通过 `_handlers` 字典将 `required_skill` 字符串映射到具体的私有处理方法，实现执行逻辑的分发。
- 统一的数据序列化协议：所有核心数据模型 (`Task`, `HostInfo`, `AgentCard` 等) 均在 `protocol.py` 中定义为 dataclass，并提供标准的 `to_dict()` 和 `from_dict()` 方法用于 JSON 交互。
- 异步非阻塞的任务分发：`Orchestrator` 在分发子任务时使用 `threading.Thread` 启动后台线程执行 HTTP 请求与结果收集，避免阻塞主调度循环。
- 基于环境变量的敏感配置隔离：所有 LLM API Key 与 Bot Token 均通过 `os.environ.get()` 读取，严禁硬编码在源码或 YAML 配置文件中。
