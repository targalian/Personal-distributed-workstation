- **分层架构**：采用 `StationController`（基础设施/管理）与 `WorkerAgent`（执行/代理）分离的C/S模式，通过UDP广播发现与HTTP心跳维持集群状态。
- **PM Agent核心驱动**：`ProjectManagerAgent` 运行于 Worker 节点，利用 `multi-agent-architect` 技能进行任务复杂度分析与拓扑排序，自主决策协作模式（Single/Orchestrator/Teams）并分发子任务。
- **动态运行时**：`AgentRuntime` 支持多Provider LLM路由与降级链，并通过 `custom_system_prompt` 机制实现 PM 对子 Agent 的动态 Prompt 注入与中途纠偏。
- **数据持久化**：`Database` 模块基于 SQLite 统一管理主机注册、Agent Card、任务生命周期、PM 状态及进度报告，支持线程安全访问。
- **交互接口**：`station_api.py` 提供 RESTful API 与 WebSocket 实时推送，集成 `ChatHandler` 实现具备意图检测与状态感知的秘书对话接口。
