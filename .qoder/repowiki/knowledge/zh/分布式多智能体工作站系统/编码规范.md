- 采用 Pydantic dataclass 定义协议模型（如 `HostInfo`, `Task`, `PMAgent`），并提供 `to_dict`/`from_dict` 方法用于 JSON 序列化与数据库交互。
- 所有网络通信与耗时操作（如 LLM 调用、子任务分发）均在独立线程或异步后台任务中执行，避免阻塞主事件循环或 HTTP 请求处理。
- 模块间通过控制器实例（如 `StationController`, `WorkerAgent`）进行依赖注入与状态共享，而非直接引用全局变量，确保组件的可测试性与解耦。
- 统一使用 `uuid4` 生成短哈希 ID（如 `pm-{hex[:12]}`, `task-{hex[:12]}`）作为业务主键，兼顾唯一性与可读性。
