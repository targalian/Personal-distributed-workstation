- **分层架构**：采用 `StationController` (控制层/入口) -> `StationDirector` (业务逻辑/资源管理) -> `Database`/`DiscoveryService` (基础设施层) 的分层设计。
- **核心组件**：`StationDirector` 专注主机评级（S/A/B/C/D）与资源池维护；`StationController` 负责协调 UDP 发现、HTTP API 服务及 Secretary 组件（ProjectManager, ModelRouter 等）的动态加载。
- **接口边界**：通过 `station_api.py` 暴露 RESTful API 和 WebSocket 实时推送，支持 Worker 节点注册、心跳上报及远程角色分配。
- **依赖方向**：控制层依赖业务逻辑层，业务逻辑层依赖数据持久化层 (`database.py`) 和网络发现层 (`discovery.py`)，遵循单向依赖原则。
