- **动态角色分发**：Station Director 作为控制平面，通过 HTTP 远程指令在 Worker 节点上按需激活 Secretary（子进程）或 PM Agent（内嵌模块），实现计算资源的弹性调度。
- **PM 驱动的执行流**：摒弃中心式 Orchestrator，由运行在 Worker 上的 PM Agent 利用 `multi-agent-architect` 技能自主决策团队拓扑、分解任务并管理子 Agent 生命周期。
- **分层治理边界**：Station Director 专注主机评级与资源池维护，Secretary/PM 专注项目预算与任务逻辑，两者通过共享 SQLite 与 WebSocket 实时同步状态。
- **标准化通信契约**：基于 UDP 发现与 HTTP API 构建统一的注册、心跳及任务分发协议，确保异构节点间的无缝协作。
