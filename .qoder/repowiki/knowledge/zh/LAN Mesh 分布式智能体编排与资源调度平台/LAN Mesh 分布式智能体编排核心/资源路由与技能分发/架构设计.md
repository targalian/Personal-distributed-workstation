- **分层架构**：模块采用“协议定义-数据持久化-业务逻辑”的分层设计。`protocol.py` 定义了 `RoutingResult`、`Project`、`SkillRecord` 等核心数据契约；`database.py` 提供基于 SQLite 的线程安全持久化支持；上层由 `ModelRouter`、`ProjectManager` 和 `SkillRegistry` 分别实现路由决策、成本控制和技能分发逻辑。
- **依赖方向**：业务组件（如 `model_router.py`）依赖 `protocol.py` 进行数据交互，并通过 `project.py` 获取项目级策略（如预算阈值、模型白名单），形成策略驱动的路由闭环。
- **接口边界**：`SkillRegistry` 作为 Station Director 的核心组件，通过扫描文件系统并解析 YAML front matter 来维护技能元数据，为 Worker 节点提供基于角色和 Agent ID 的动态技能包构建能力。
