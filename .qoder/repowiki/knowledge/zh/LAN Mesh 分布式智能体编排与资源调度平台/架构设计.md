- **双模态控制平面**：采用 `StationController`（纯基础设施模式）与 `SecretaryController`（全功能编排模式）的双入口设计。通过 `/api/station/activate-secretary` 实现同进程热加载项目管理组件（ProjectManager, ModelRouter, MCPGateway），支持在“机器管理”与“项目执行”间动态切换。
- **PM Agent 远程激活机制**：摒弃传统的中心化 Orchestrator 直调模型，演进为 Secretary 接收任务后，根据主机评级（Rating Tier）动态选择最优 Worker，并通过 HTTP (`/role/start-pm`) 远程注入 PM Agent。PM Agent 利用 `multi-agent-architect` skill 自主决策团队架构并分发子任务。
- **分层通信协议**：底层基于 UDP 广播（端口 45454）实现零配置设备发现与心跳保活；上层基于 FastAPI 提供 RESTful 接口进行主机注册、任务提交及状态同步，并通过 WebSocket 实现前端仪表盘的实时数据推送。
- **统一数据持久化边界**：所有子模块共享 `Database` (SQLite) 作为唯一事实来源，统一管理 `HostRecord`（基础设施）、`AgentCard`（能力声明）、`Task`（业务逻辑）及 `PMAgent`（运行时状态），确保跨模块状态的一致性。
