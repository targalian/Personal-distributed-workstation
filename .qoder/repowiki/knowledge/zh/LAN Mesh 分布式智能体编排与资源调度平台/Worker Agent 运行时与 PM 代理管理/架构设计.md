- **入口与状态管理**：`worker.py` 定义了 `WorkerAgent` 类，作为守护进程的核心，通过 `WorkerState` 维护设备身份、共享文件夹、Agent 运行时及 PM 代理实例。
- **能力声明机制**：`agent_card.py` 实现了 A2A 协议的 Agent Card 生成逻辑，将 Worker 的技能（Skills）和工具（Tools）标准化为 JSON 结构，供 Secretary 进行任务匹配。
- **任务执行引擎**：`agent_runtime.py` 提供了 `AgentRuntime` 类，根据技能类型（如代码生成、审查、Shell 执行）路由到不同的处理器，并支持多模型提供商（DeepSeek, OpenAI 等）的降级调用。
- **PM 代理集成**：`pm_agent.py`（虽在 scope 外但被引用）实现了 `ProjectManagerAgent`，由 `worker.py` 内嵌管理。Worker 提供 `/role/start-pm` 和 `/pm/create-subagent` 等 API，允许 Secretary 远程激活 PM 并在本地或远程站点创建子代理。
- **提示词工程**：`agent_prompt.py` 提供了动态构建子代理 System Prompt 的工具，支持注入团队上下文、依赖关系和质量要求，确保子代理行为符合 PM 的架构决策。
- **工具注册表**：`tool_registry.py` 实现了插件化的工具管理系统，支持内置工具（文件读写、HTTP 请求等）和基于 YAML 配置的动态加载，遵循 MCP 兼容格式。
