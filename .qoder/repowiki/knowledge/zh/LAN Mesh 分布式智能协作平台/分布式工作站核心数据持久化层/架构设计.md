- **单例封装模式**：通过 `Database` 类统一封装所有 SQL 操作，利用 `threading.local` 实现线程级连接隔离，确保多线程环境下的并发安全。
- **逻辑分层设计**：内部按业务域划分为五大模块——基础设施（Hosts/Heartbeats）、智能体管理（Agents/Skills）、任务编排（Tasks/Projects）、PM 架构演进（PMAgents/Teams）及审计日志（Usage/Events）。
- **动态 schema 演进**：在 `_init_db` 中采用 `ALTER TABLE ... ADD COLUMN` 配合异常捕获机制，实现数据库结构的向后兼容与平滑升级，避免破坏现有数据。
- **复杂对象序列化**：针对 `skills`、`subtasks`、`team_structure` 等复杂字段，统一采用 JSON 字符串存储在 TEXT 列中，并在 CRUD 接口层完成 `json.dumps/loads` 转换，保持关系型数据库的简洁性。
