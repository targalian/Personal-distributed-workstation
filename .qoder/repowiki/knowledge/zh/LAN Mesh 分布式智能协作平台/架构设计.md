- **控制平面**：采用 Station/Worker 主从架构，Station 作为中央控制器管理主机注册、评级与资源池，Worker 作为执行节点上报状态并接收指令。
- **动态角色路由**：支持 Secretary（秘书）角色的动态激活与迁移，既可在 Station 进程内加载，也可通过 HTTP 远程调度至高性能 Worker 节点运行，实现控制逻辑与计算资源的解耦。
- **分层智能编排**：引入 PM Agent（项目经理）作为任务分解与调度的核心，由 PM 在 Worker 上实例化并动态创建子 Agent 团队，形成“Station 管资源、PM 管任务、Agent 管执行”的三层协作模型。
- **统一通信契约**：基于 UDP 广播实现零配置设备发现，结合 HTTP API 进行结构化数据交换（注册/心跳/任务分发），并通过 WebSocket 实现前端仪表盘的实时状态推送。
