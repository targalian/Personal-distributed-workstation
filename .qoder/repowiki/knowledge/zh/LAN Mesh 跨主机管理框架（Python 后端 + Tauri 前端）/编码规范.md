- 每个控制器类（StationController / WorkerAgent）配套一个同名 `@dataclass` State（如 StationState / WorkerState）保存运行时共享字段，统一以 `self.state.xxx` 访问。
- 配置读取采用「显式路径 → 环境变量 → 包内默认 → 空默认」的多级候选链模式，由 `load_config()` / `load_model_pool()` 等函数集中实现，避免硬编码路径。
- 模块间导入采用延迟 import（在方法体内 `from .xxx import ...`），将重型组件（ProjectManager、ModelRouter、MCPGateway、ChatHandler）按需加载，降低冷启动开销。
- 设备身份通过 `load_or_create_device_id(data_dir, role)` 生成并持久化到 `~/.lan_mesh/device_id.json`，不同角色各自独立 ID，便于区分 station/worker。
- Web UI 模板与静态资源统一从 `Path(__file__).parent / "web"` 下的 `templates/` 与 `static/` 目录挂载，FastAPI 通过 `StaticFiles` 和自定义 HTMLResponse 提供服务。
