- **进程角色三态**：`main.py` 通过 `argparse` 分发为 `station`（基础设施管理 + Web UI）、`secretary`（中心控制节点，含项目管理/编排/MCP 网关）和 `worker`（各主机守护进程）。`StationController` 支持同进程动态 `activate_secretary()` / `deactivate_secretary()`，实现「纯基础设施模式」与「项目管理模式」无缝切换。
- **通信协议分层**：`protocol.py` 统一定义 DiscoveryPacket/HostInfo/AgentCard/Task/SubTask/PMAgent 等 dataclass 载荷；`discovery.py` 基于 UDP 45454 端口广播存在包，`api.py` 暴露 FastAPI REST（Worker `/info`、Secretary `/api/register`、`/api/heartbeat`、`/ws` 实时推送），心跳间隔 5s、TTL 12s。
- **配置与数据体系**：`config.py` 使用 Pydantic v2 BaseModel 强类型校验，按「显式参数 → LAN_MESH_CONFIG/LAN_MESH_MODEL_POOL 环境变量 → ~/.lan_mesh/config.yaml → ./config.yaml」多级候选链加载；`database.py` 以 SQLite 持久化 hosts/agents/tasks/projects/skills/pm_agents 等表，并通过 `ALTER TABLE IF NOT EXISTS` 兼容历史 schema 演进。
- **高级能力集成**：Worker 侧运行 PM Agent 子进程处理复杂任务，`mcp_gateway` 暴露 MCP 工具，`skill_registry` 扫描 `skills/` 目录注册技能，`bot_gateway` 集成企业微信/Telegram 通道；`model_router` 基于 `model_pool.yaml` 做 L1-L4 难度分级路由。
- **前端技术栈**：独立 Tauri 桌面应用 `quicklan-main/`，Rust 后端复用 LAN 发现协议，通过 Tauri commands 调用本地 API，React+Vite 渲染仪表盘。
