## 1. 技术栈与核心方法
- **框架**: React + TypeScript (Vite 构建)。
- **样式方案**: 纯 CSS (Vanilla CSS)，未使用 Tailwind、Sass 或 CSS-in-JS 库。
- **图标库**: `lucide-react`，提供统一的线性图标风格。
- **桌面集成**: Tauri v2，通过 `tauri.conf.json` 配置窗口尺寸（1120x760）和拖拽支持。

## 2. 设计语言与视觉规范
- **色彩体系**:
  - **背景色**: 浅灰蓝基调 (`#f6f8fb`)，面板使用纯白 (`#ffffff`)。
  - **主色调**: 科技蓝 (`#176bc3`, `#2276d2`)，用于主要按钮、选中状态和进度条。
  - **文本色**: 深灰蓝 (`#17202a`) 作为标题，次级文本使用中性灰 (`#4d667e`, `#65798d`)。
  - **状态色**: 绿色 (`#15935d`) 表示在线/成功，红色 (`#a8241a`) 表示错误/危险操作。
- **排版与字体**:
  - 优先使用 `Inter`，回退到系统默认无衬线字体。
  - 强调字重：大量使用 `font-weight: 800` 增强标签和按钮的视觉冲击力。
  - 字号层级：标题 30px，副标题 17px，正文 13px。
- **形状与间距**:
  - **圆角**: 统一使用 `8px` (面板、卡片) 和 `7px` (按钮、输入框)。
  - **边框**: 细边框 (`1px solid #dce4ed`) 配合浅色背景，营造清爽的“卡片式”布局。
  - **阴影**: 仅在模态框 (`modal`) 和 Toast 提示中使用柔和阴影，提升层级感。

## 3. 组件化样式约定
- **布局系统**: 广泛使用 CSS Grid (`.grid`, `.form-grid`) 和 Flexbox (`.topbar`, `.tabs`) 实现响应式对齐。
- **交互反馈**:
  - **Tab 切换**: 激活态增加蓝色边框和浅蓝背景 (`#eaf4ff`)。
  - **设备列表**: 选中项高亮显示 (`#eef6ff`)。
  - **进度条**: 带有平滑过渡动画 (`transition: width 180ms ease`)。
- **响应式策略**: 在 `920px` 断点处将双栏布局折叠为单栏，并调整顶部导航栏为垂直排列。

## 4. 开发者指南
- **新增样式**: 直接在 `src/styles.css` 中追加类名，遵循 BEM 风格的命名习惯（如 `.panel-title`, `.device-main`）。
- **图标使用**: 从 `lucide-react` 导入图标组件，统一设置 `size={16}` 或 `size={17}` 以保持视觉平衡。
- **主题扩展**: 若需支持深色模式，建议在 `:root` 中定义 CSS 变量并替换硬编码的颜色值。
