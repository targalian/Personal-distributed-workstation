- **进程角色架构**：通过 `main.py` 分发为三种核心角色——`station`（基础设施管理 + Web UI）、`secretary`（中心控制节点，含项目管理/编排/MCP 网关）和 `worker`（各主机守护进程）。`station` 支持动态激活/停用 `secretary` 组件，实现「纯基础设施模式」与「项目管理模式」的无缝切换。
- **通信协议设计**：采用 UDP 广播（端口 45454）进行设备发现与状态上报，HTTP REST 用于 Worker 向 Secretary 注册、心跳维持及文件下载，WebSocket 用于实时推送主机状态与任务进度。
- **配置与数据体系**：使用 Pydantic v2 强类型校验配置，按「显式参数 → 环境变量 → 用户目录 → 项目根」顺序加载；底层采用 SQLite 持久化主机信息与项目状态，并通过 `SharedFolderManager` 在各节点维护统一的协作空间。
- **高级能力集成**：在 Worker 侧运行 PM Agent 子进程处理复杂任务，通过 `mcp_gateway` 暴露 MCP 工具，利用 `skill_registry` 扫描并注册技能，同时集成企业微信/Telegram 等 Bot 通道实现消息推送。
- **前端技术栈**：包含独立的 Tauri 桌面应用 `quicklan-main/`，Rust 后端复用 LAN 发现协议，通过 Tauri commands 调用本地 API，React+Vite 渲染仪表盘。
