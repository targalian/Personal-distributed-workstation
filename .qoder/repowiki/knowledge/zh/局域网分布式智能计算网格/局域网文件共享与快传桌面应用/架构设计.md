- **前端层 (React + Vite)**: `src/App.tsx` 作为单一入口，通过 URL 参数区分主窗口与接收弹窗，利用 `@tauri-apps/api` 调用后端命令并监听事件驱动 UI 更新。
- **后端核心 (Rust/Tauri)**: `src-tauri/src/lib.rs` 初始化 `AppState`，集成 `DiscoveryService`（UDP 广播/组播发现）、`TransferService`（TCP 点对点传输）和 `LibraryService`（本地 SQLite 索引管理）。
- **通信协议**: 采用自定义二进制/JSON 混合协议。控制面使用 UDP 广播交换 `DiscoveryPacket`；数据面使用 TCP 长连接，通过长度前缀帧传输 `TcpHeader` 及文件流，支持 SHA256 完整性校验。
- **外部控制接口**: `control_api.rs` 在本地回环地址启动轻量级 HTTP 服务器，允许外部脚本（如 Codex）触发窗口显示或发起文件发送请求，实现自动化集成。
