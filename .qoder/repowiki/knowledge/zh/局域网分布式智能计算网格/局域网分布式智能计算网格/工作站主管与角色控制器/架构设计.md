- **核心分层**：`StationDirector` 封装基础设施逻辑（主机注册、心跳处理、S/A/B/C/D 评级算法），`StationController` 作为独立入口协调 UDP 发现、数据库持久化及 Web UI。
- **动态角色演进**：采用同进程热加载机制，通过 `activate_secretary` 动态注入 `ProjectManager`、`Orchestrator` 等业务组件，实现从纯资源监控到任务编排的模式切换。
- **接口边界**：`station_api.py` 提供统一 FastAPI 路由，利用 `_check_secretary` 中间件根据激活状态隔离基础查询与高级业务接口；`worker.py` 暴露 `/role/start-secretary` 端点支持远程角色分配。
- **依赖方向**：控制器层依赖 `database` 和 `discovery` 服务，业务组件（如 MCP 网关）仅在 Secretary 模式激活后初始化，遵循按需加载原则。
