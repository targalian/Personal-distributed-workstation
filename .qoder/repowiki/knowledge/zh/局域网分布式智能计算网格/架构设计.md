- **统一入口路由**：`main.py` 作为核心 Orchestrator，根据 `station`、`secretary`、`worker` 角色参数动态加载对应的控制器（`StationController`、`SecretaryController`、`WorkerAgent`）。
- **配置驱动隔离**：通过 `config.yaml` 统一定义发现协议端口（UDP 45454）及各角色 API 端口，确保不同节点在共享网络环境下的通信契约一致。
- **标准化启动流程**：提供跨平台（Shell/PowerShell/Batch）的启动脚本，封装虚拟环境检测与参数透传逻辑，简化多节点部署复杂度。
- **职责演进架构**：引入 `Station Director` 作为独立的管理平面，与执行平面（Worker）和协调平面（Secretary）解耦，支持通过 Web UI 进行舰队管理与角色激活。
