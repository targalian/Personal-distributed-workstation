## Credits 计费机制

- Credits 统一抵扣全部模型与 Harness 工具; 单次消耗由模型类型、Token 用量、
  思考模式、工具调用**动态决定** — 官方未公布固定 Credits/token 换算表
- 视频等异步任务完成后统一结算
- 夜间权益 (限时): **qwen3.8-max 与 deepseek-v4-pro-0813 每晚 22:00-08:00 五折**

## 使用约束 (合规红线, 直接影响调度策略)

- **严禁 API 调用**: 仅限编程/智能体工具交互式使用 (Claude Code、Cursor、
  Qoder、Qoder CN 等); 自动化脚本、应用后端、非交互式批量调用 = 违规,
  可致订阅暂停或 Key 封禁
- 禁止共享账号; **仅限单台设备**, 多设备同时登录调用有封禁风险
- 订阅到期重购会变更 API Key; 个人版不支持退订; 同一实名主体限购一份

## R5-2 量化要点 (推导)

- 订阅池价值 ≈ 月费 ÷ 7 天限额 Credits → Lite 0.0156 / Standard 0.0139 /
  Pro 0.0125 元/Credit; 加油包 0.005 元/Credit (边际成本最低)
- Credits/token 换算不透明 → 无法精确折算每池单位 token 价值, 量化公式宜以
  "Credits 消耗速率 + 窗口剩余天数" 为调度信号而非绝对价格
- 桥梁模型: glm-5.2 (百炼 ∩ 火山方舟), deepseek-v4-pro (百炼 ∩ DeepSeek 按量)
  → 跨池轮换优先消耗订阅额度, 保留按量余额
- 调度红线: 非交互式批量场景 (nightly loop 等) 不得路由至订阅池
