## 使用约束 (合规红线)

- **不可用于 API 调用**: 套餐额度仅在 AI 编程工具中生效 (Claude Code、TRAE、
  Cursor、Cline、OpenCode 等); 非编程工具使用专用 Base URL + Key 可能被判定
  滥用 → 订阅停用或账号封禁
- 专用 Base URL: Anthropic 协议 `https://ark.cn-beijing.volces.com/api/coding`,
  OpenAI 兼容 `https://ark.cn-beijing.volces.com/api/coding/v3`;
  未用指定 Base URL 无法消耗套餐额度且可能产生 API 费用
- 同一订阅额度所有工具共享; 高峰不明显降速 (未公布具体并发数值)
- 面向个人开发者; 企业批量调用需走方舟模型 API 按量付费

## R5-2 量化要点 (推导)

- 请求制计量 → 单次请求价值 = 月费 ÷ 月请求上限:
  Lite 40/18000 ≈ 0.0022 元/次, Pro 200/90000 ≈ 0.0022 元/次 (档位等价);
  活动价期间实际价值 ×2.5 倍
- 模型系数即"请求购买力消耗倍率" → glm-5.2/kimi-k2.7-code 每请求消耗约
  为 doubao-lite 的 9 倍 (4.5/0.5); **量化公式可直接以系数为能力/成本档位代理**
- 调度建议: 日常任务路由 doubao-seed-2.1-turbo (系数 2.5) 或
  deepseek-v4-flash (系数 0.5), 高系数模型留给重难点任务
- 桥梁模型: glm-5.2 (方舟 ∩ 百炼), deepseek-v4-flash/pro (方舟 ∩ DeepSeek 按量 ∩ 百炼)
- 调度红线: 非 AI 编程工具场景不得路由至本池
