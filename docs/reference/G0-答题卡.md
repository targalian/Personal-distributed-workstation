## ★ Q1 方向优先级

三个方向 (1 平台化 / 2 智能化RL / 3 基础迭代) 先做哪个?

我的建议: **方向3 先行**。理由是风险最低、能立刻产出可验证收益, 且它的产物
(模块分层、统计指标口径、数据管线提速) 正好是方向1 抽策略 DSL、做回测服务的地基,
也是方向2 定义奖励函数的前提。

答: 基础迭代


## Q2 方向1 分发形态

「面向大众的平台」是公网 SaaS (要账号体系/风控/合规), 还是本地或内网分发的工具?
