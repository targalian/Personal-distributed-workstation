# 服务与后台所有权（iter-110）

主机、配置同步、自愈、发现传输与设备查询、云传输、Bot 通道/发送/入口、MCP 连接/工具、
优化和影子队列分别进入实例级领域服务。PM 的 Planner/Dispatcher/Monitor 与 DAG、
序列化、密码学等已有明确边界的普通组件继续保留，未为纯辅助函数增加消息地址。

Application lifecycle 是应用装配层：先停止生产者与周期等待，再请求取消执行，
按共同截止时间等待所属线程退出，最后关闭子服务作用域和根容器。
所有周期等待使用可唤醒 stop token；MCP 健康检查新增幂等启动和停止，发现服务停止时关闭
监听 socket，云同步停止时唤醒等待，Bot 停止聚合器和轮询。Station/Worker 的正常服务器
退出和 FastAPI shutdown 均进入同一清理路径，WS 后台协程保存引用并取消、等待完成。

Yomk 运行时跟踪请求数：close 拒绝外部新请求，在途请求仍可完成嵌套调用，最后一个请求
退出才调用框架 shutdown。拥有后台线程的组件先退役线程后销毁容器；根应用停止后禁止隐式
重建服务。默认资源台账在生产者结束前保持可记账，最后排空后关闭。

资源热重载先等待旧上报/WS/预警线程退出，不能退出时明确拒绝重载，避免清除旧 Event 后
同时复活多个线程。事件总线解除订阅校验 sink 身份，旧应用不能移除新应用的订阅。
HTTP/WS 批量记账均使用线程池。

关闭返回 stopped/pending/errors；外部 CLI 和尚在网络等待的工作不被冒充为已停止。
挂起线程保留所有权并延后释放，未承诺任意用户子进程能被立即强杀。

新增行为回归：在途请求排空与嵌套完成、拒绝重建、旧资源线程退出后热重载、MCP 健康线程
停止与幂等、旧 sink 隔离。全量 612 passed（139.19s），未包含真实多机或供应商线上调用。
