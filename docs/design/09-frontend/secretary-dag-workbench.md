# 秘书对话与任务流程工作台（iter124）

用户可在秘书对话中打开“任务流程”，并排查看任务依赖与对话。点选步骤后，“带着这一步与秘书讨论”只把任务标识和步骤名称填入输入草稿；用户补充并发送后才调用既有秘书入口。未关联项目的对话只列已绑定PM线程的任务，已关联项目的对话列该项目任务。切换对话重新解析服务端归属，不能沿用上一对话的流程。

## 组件与入口

`web/static/dag/`是Web和React共用的静态工作台。`model.js`负责依赖校验、拓扑排版和草稿比较；`canvas.js`负责SVG绘制、键盘、指针平移/节点移动及缩放；`workbench.js`负责身份、读取、编辑和保存；`style.css`与`chat.css`分别服务工作台和对话布局。使用现有MeshTransport、任务/图/对话/PM线程API，没有新增后端端点或改变角色授权。

- 秘书：`dashboard/dag.js`在当前对话侧栏装载工作台，来源和iframe窗口均匹配后才接受消息。
- 项目工作台：任务卡片“DAG”直接打开指定任务；初次装载通过URL携带任务，避免下拉列表异步刷新丢失选择。
- React：`DagEditorPage.tsx`复用同一工作台；hash导航和身份切换前检查草稿。Vite开发代理新增`/static`，生产资源随SPA构建更新。
- 独立页：`/static/dag/index.html?task_id=...`可直接打开；“与秘书讨论”跳转对应项目对话，不自动创建或发送消息。

## 阅读与编辑

节点按真实依赖进行拓扑排版，分支并列、合流有明确箭头；宽画布横向、窄画布纵向，窄屏首次展示保留可读字号而非无限缩小。支持搜索并定位、自动排版、适应画布、缩放、拖动空白平移、当前视图拖动节点和展开/还原。状态同时使用文字和颜色。节点与连线可通过键盘选中，任务名称和描述通过textContent显示。

详情显示步骤说明、技能、负责人、前置/后续步骤及连线条件。进入编辑模式后可修改名称、说明和技能，增删步骤与依赖，支持撤销/重做。依赖弹窗提前拒绝自环、重复边、缺失端点和循环；删除节点提示影响的依赖数。条件表达式在本轮仅展示。

查看与编辑明确区分：仅pending任务且角色为boss/operator时可编辑；运行中或结束的任务保持查看。节点布局是当前视图设置，不声称服务端已持久化拖拽坐标。保存保留原图中的其他任务字段，并读回服务端结果以建立下一次修改基线。

## 草稿与并发边界

切换任务、对话、关闭流程、离开React编辑页以及刷新/关闭浏览器时检查未保存修改。保存失败保留草稿，失败加载不改变已加载任务身份。保存前重新读取任务状态和图，发现远端变更即停止覆盖；秘书回复或任务图事件触发重新核对，有草稿时只提示更新。

此处是前端保存前检查，不是服务端原子compare-and-swap；两次读取/写入间的极短竞态仍由既有服务端行为决定。没有新增多人实时协同或草稿跨浏览器持久化。草稿与各对话输入内容只保存在当前页面内存，用户确认放弃或刷新后不会恢复。

秘书输入框支持多行、Shift+Enter换行、中文输入法组合期间不发送。HTTP失败会保留可重试文本；HTTP和WS回复按内容/时间去重，包含conv_id的回复只进入对应对话。切换对话时过期历史响应不覆盖当前消息。用户阅读上方历史时，新消息保留滚动位置并显示“查看新消息”。
