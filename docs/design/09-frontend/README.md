## 项目描述编辑器

「AI 建议」视图默认不勾选变更，支持逐项选择／全选／忽略；结构变更作为整体，显示人可读节点与依赖对照。通过 `/review` 保存所选并清除建议；UI 在未保存本地修改或基准版本过期时禁用采纳。聊天 WS 通过 `brief_proposal_id` 触发刷新，即使文档还处于 v0 也能显示建议。勾选状态按会话保留于页面，建议本身由服务端持久化。

「版本历史」通过分页接口读取持久化元数据，查看某一版本时由服务端生成相对当前已保存文档的差异。恢复目标明确标为「所看版本」，需确认；存在未保存草稿、尚未查看差异或页面版本落后时禁用。恢复会创建新版本并保留页面撤销能力；请求响应按会话与加载序号校验，避免跨会话误更新。

`project-brief.js` 与 `project-brief.css` 在秘书聊天旁提供产物工作区。`ProjectBriefUI.open()` 绑定当前对话，`flush()` 在聊天前保存手工编辑，`refresh()` 同步秘书输出并保护未保存草稿。需求 DAG 支持 SVG 拖动、三层嵌套、折叠、依赖校验、缩放平移和撤销／重做；与 PM 执行 DAG 分开存储。异步加载不覆盖加载期间的新输入；保存响应即使晚于对话切换，也会更新原对话草稿的版本与同步状态。

iter-37 将历史按钮移至顶部，文档、图和预览共用 50 步历史。每个会话保存 `savedDocument` 基线，按值比较决定 dirty 状态，忽略 API 对对象字段顺序的调整；撤销不回退服务端 revision。保存及相同版本加载保留历史，显式重载／外部新版本清空历史，冲突保留历史。连续同字段输入按 1 秒窗口合并，失焦、图编辑、切换视图及保存结束分组；空操作不清空 redo。键盘事件限定在工作区内，节点属性未提交时沿用原生文本撤销。历史快照只存在页面内存中，不作为服务端版本存储。

## iter-48 / UI-041：任务结果核实

任务卡片展示未知结果提示；详情提供原诊断、原节点核实按钮、核实时间和下一步建议。查询期间禁用按钮，错误可重试；输出采用 textContent，旧任务查询返回后通过 DOM 归属检查防止覆盖另一任务。桌面/手机与真实任务 API 已通过 Chrome 验证，状态查询不修改任务与验收结论。

## iter-49 / UI-042：停止状态与重发

任务卡片/详情区分停止意图与 PM 确认；未知状态提供明确重发入口，隐藏快捷重提并保留任务记录。取消/暂停与 WebSocket 提示使用服务端确认文案，不以HTTP成功码直接宣称已停止。已确认任务重提之前提醒核对在途工具和副作用。浏览器用真实任务 API 与 PM 实例验证，外部工具不实际执行。

## iter-50 / UI-043：重启待核实

任务卡片和详情统一显示执行待核实；识别 `_pm_recovery` 和旧interrupted绑定记录，隐藏快捷重提。重新提交前读取服务端当前任务，阻止旧标签页缓存失败/中断状态而误建新任务。原PM回报后刷新移除恢复诊断。Chrome验证桌面/手机、旧中断保护、过期重提拦截与回报清理。

## 重提交互（iter-51 / UI-044）

快捷重提先读取当前任务，再调用服务端重提入口；请求进行中按任务编号去重。已有重提映射或交付时隐藏新建替代任务按钮。对已执行任务提示核对在途工具、已有产物与费用；反馈同时显示替代任务编号及实际状态，不宣称执行成功。

任务详情展示来源/替代任务并提供查看入口；「重试提交请求」复用同一替代任务，可处理准备后尚未派发的情况。替代任务已删除时显示错误，保留来源记录。Chrome 验证覆盖丢失响应、重复点击、GET 后源状态变化、桌面与手机详情；仅 PM 执行为模拟。

## 执行现场核实（iter-52 / UI-045）

「核实原节点」在原有启动/当前 PM 证据之外显示持久化现场版本、中文阶段、完成/待核实/未派发数量和交付确认提示。缺失旧版记录、记录不可读取、当前实例写盘故障分别提示；所有内容用 textContent 渲染。现场不等于当前执行状态，也不开放重启续跑。Chrome验证桌面/手机、旧记录和故障提示，接口不暴露原输入/输出。

## 恢复前逐项核实（iter-53 / UI-046）

任务详情增加「核实恢复条件」，单独显示每个步骤的原执行编号和证据，区分已保存输出与待质量检查回执。时间预算用完提供「继续核实剩余步骤」，固定检查点版本并保留前批内容；版本变化提示重新核实。请求失败可重试，迟到响应不覆盖另一任务。全程只读，不提供续跑按钮。

## 显式恢复原任务（iter-54 / UI-047）

「核实恢复条件」读取现场后，符合恢复格式和状态时显示「恢复原任务」。用户确认后提交固定检查点版本；服务端重新排除原进程并校验业务授权。等待期间禁用恢复与核实按钮，失败保留重试，同一版本复用请求；已接管后隐藏恢复按钮，迟到响应不覆盖其他任务。原节点摘要区分旧版现场和可申请恢复的新版现场。Chrome 已验证真实 API/SQLite 与 PM 线程完成恢复交付，执行器模拟。
