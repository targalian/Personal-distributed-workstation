# 全量功能测试与 debug（iter-114，2026-10-27）

## 故障定位与修复

用户报告站点为 0、秘书启动失败。实际运行服务显示 4 台已登记主机、1 台在线，秘书 active。
匿名访问受保护 API 为 401；多用户模式不向未登录者发放 mesh token，仪表盘却缺少登录入口，
并将错误 JSON 当作空数据渲染。认证和权限规则保留，修复客户端展示与流程。

- 仪表盘新增个人令牌登录、无效令牌提示和退出，未认证计数显示“—”，不再冒充 0 台。
- HTTP 非成功响应抛出可读错误；秘书管理按钮仅 Boss 可用，Operator/Viewer 的服务端限制保持。
- 身份切换及退出清除旧 mesh 凭证，防止匿名请求复用此前 Boss 凭证；失效身份不回退提权。
- 普通 WS 在发送主机数据前认证，浏览器通过子协议传令牌，不放入 URL/访问日志。
  React 和仪表盘共用相同身份逻辑；未登录不连接，登录后加载数据，退出关闭连接。
- 有效个人令牌与节点令牌使用可信限流桶，避免正常页面并发请求误用匿名低额度桶。
- Secretary 的激活和停用在每个 owner 上串行，避免选举/failover 同时初始化或清理重叠。
- PWA 缓存升级为 v3。原接口路径、HTTP 数据结构、数据库主键及任务执行器不变。
